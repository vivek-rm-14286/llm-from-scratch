# Ticket Router: a Calibrated Decision Model

Code for [Project 3](https://vivek-rm-14286.github.io/llm-from-scratch/#/projects/ticket-router) of the site.

Route incoming Nimbus Monitor support messages to one of seven queues, with calibrated
probabilities and an "escalate to a human" rule. Three models are trained and compared on the
same held-out set: frozen embeddings + logistic regression, a fine-tuned encoder, and a
decision language model that scores all options in one forward pass.

## Layout

```text
starter/    signatures, docstrings and TODOs: write the bodies yourself
solution/   the reference implementation (same file names)
tests/      pytest suite, runs against either package
data/       generated by `python -m solution.data` (git-ignored; seed 0 always gives the same files)
out/        models, logits, report, plots, router.json (git-ignored)
```

| File | What it does |
|---|---|
| `bank.py` | the text bank: queues, intents, phrasings, short messages, OOD messages (complete in both packages) |
| `data.py` | the synthetic inbox generator |
| `metrics.py` | accuracy, macro-F1, ECE, temperature fitting, cost-weighted threshold |
| `train_baseline.py` | (a) `BAAI/bge-small-en-v1.5` embeddings + logistic regression |
| `train_encoder.py` | (b) the same encoder fine-tuned end to end with a classification head |
| `decision_lm.py`, `train_decision_lm.py` | (c) `HuggingFaceTB/SmolLM2-135M` as an order-invariant option scorer |
| `calibrate.py` | temperature scaling, ECE, reliability diagram, threshold, confusion matrix, `router.json` |
| `benchmark.py` | p50/p95 latency per request on CPU |
| `router.py` | `load_router()`: the entry point other projects call |

## Setup

```bash
cd code/ticket_router
uv venv && source .venv/bin/activate
uv pip install -r requirements.txt
```

No GPU is needed. The first run downloads two checkpoints (about 130 MB and 270 MB).

## Run the reference solution

```bash
python -m solution.data                 # 1600 train, 500 calibration, 1000 test, 200 OOD messages
python -m solution.train_baseline       # 12 s
python -m solution.train_encoder        # about 3 minutes on CPU
python -m solution.train_decision_lm    # about 21 minutes on CPU (--device mps: about 5x faster per step on a Mac)
python -m solution.calibrate            # report + out/reliability.png + out/confusion.png + out/router.json
python -m solution.benchmark            # per-request latency
python -m solution.router "we were charged twice" "getting 403"
```

Smoke test of the whole pipeline in about one minute (it checks the plumbing only: one epoch on 200
messages leaves the encoder and the decision LM near chance):

```bash
python -m solution.data --out data_small --n-train 200 --n-cal 100 --n-test 100 --n-ood 40
python -m solution.train_baseline --data data_small --out out/smoke
python -m solution.train_encoder --data data_small --out out/smoke --epochs 1
python -m solution.train_decision_lm --data data_small --out out/smoke --epochs 1
python -m solution.calibrate --data data_small --out out/smoke
```

## Do it yourself

Work in `starter/`. Every function you have to write raises `NotImplementedError` with a
TODO that says what to do. Replace `solution` with `starter` in the commands above.

```bash
pytest                             # tests the starter: everything fails at first; make it green file by file
pytest --impl solution             # the reference passes (28 tests)
pytest --impl solution -m model    # the two tests that need SmolLM2-135M and trained artifacts
```

The default test run needs no model download and takes a few seconds.

## Using the router from other code

```python
from solution.router import load_router      # with code/ticket_router on sys.path

router = load_router()                        # reads out/router.json
router.route("Data points are rejected with NM-4012")
# {"queue": "ingestion", "probs": {"billing": 0.01, ...}, "confidence": 0.93, "abstain": False}
```

`abstain` is `True` when the calibrated confidence is below the cost-derived threshold: send
the message to a human instead of a queue. `load_router(path)` accepts another output
directory, and `load_router(model="encoder")` picks a specific model. If no trained artifact
exists, `load_router` warns and returns a keyword baseline with the same interface
(`router.name` starts with `keyword-baseline`).
